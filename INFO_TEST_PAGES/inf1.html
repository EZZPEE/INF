Comprobando conexión

Los datos locales se actualizan automáticamente.

Privacidad: al actualizar, ipapi.co recibirá tu IP pública para estimar la ubicación. El tiempo usa esas coordenadas aproximadas. Si autorizas la ubicación del navegador, sus coordenadas se enviarán a OpenStreetMap Nominatim para buscar la calle y dirección; si no, se usarán las coordenadas aproximadas por IP. La dirección depende de la precisión de las coordenadas y no confirma tu domicilio. Esta página no guarda ni envía los resultados a otros destinos.

Ubicación

La calle se busca a partir de las coordenadas del dispositivo cuando el navegador las proporciona.

Los datos técnicos dependen de las capacidades y permisos del navegador. La dirección corresponde a la calle que OpenStreetMap asocia con las coordenadas usadas; si se usan coordenadas por IP, puede reflejar la ubicación de tu proveedor o VPN y no tu calle real. Datos de mapas: OpenStreetMap.
